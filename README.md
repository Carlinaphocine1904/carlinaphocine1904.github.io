# VFA Football Website

A responsive static website starter for VFA Football / Football Fusion Roblox.

## Included
- VFA branding and uploaded logo
- Gold theme: #f6be64
- 32-team league structure
- Home page with schedule section
- Standings table
- 32-team directory
- Discord links to https://discord.gg/vfaff
- Mobile responsive layout

## Add your real schedule
Open `app.js` and edit the `schedule` array near the top:

{
  date: "Sep 26",
  home: "Your Team",
  away: "Opponent",
  time: "7:00 PM",
  week: "Week 1"
}

## Hosting
This is a plain HTML/CSS/JS site, so it can be hosted on GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any normal web host.

No backend is required for the current version.
